# 🚗 Car Price Prediction Web Application

A Machine Learning web application that predicts the estimated price of a used car based on its details.

## Features

- Predicts used car prices
- Interactive Flask web application
- Machine Learning model using Linear Regression
- HTML & CSS frontend

## Tech Stack

- Python
- Flask
- Scikit-learn
- Pandas
- NumPy
- HTML
- CSS

## Project Structure

```
CarPricePredictor/
│
├── application.py
├── Cleaned_Car.csv
├── LinearRegressionModel.pkl
├── requirements.txt
├── templates/
│   └── index.html
└── static/
    └── style.css
```

## Run the Project

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python application.py
```

Open:

```
http://127.0.0.1:5000
```
